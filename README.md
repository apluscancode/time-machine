# 🕰️ ماشین زمان — Time Machine

> «هر ۱,۰۰۰ تومان در گذشته، امروز چقدر می‌ارزد؟»

یک وب‌سایت رایگان که سرمایه‌ی شما را در یک سال شمسی **به‌ عقب** می‌برد و
نشان می‌دهد امروز در هر بازار چقدر ارزش دارد.

🔗 **نسخه‌ی زنده:** https://apluscancode.github.io/time-machine/
📦 **ریپو:** https://github.com/apluscancode/time-machine

---

## چطور کار می‌کند

```
۱) کاربر یک سال شمسی و یک مبلغ (تومان) انتخاب می‌کند
۲) برای هر بازار، «تعداد واحد» آن سال محاسبه می‌شود:
      تعداد = مبلغ ÷ قیمت آن سال
۳) ارزش امروز = تعداد × قیمت امروز
۴) ضریب بازده = ارزش امروز ÷ مبلغ اولیه
```

هر ردیف علاوه بر ارزش کل، **ارزش هر ۱,۰۰۰ تومان آن سال** را هم نشان می‌دهد
(مستقل از مبلغی که کاربر وارد کرده).

برای **سپرده بانکی** به‌جای خرید دارایی، سود سالانه‌ی مصوب هر سال
(بانک مرکزی) به‌صورت مرکب (compound) اعمال می‌شود.

## چه بازارهایی؟

| بازار | واحد | منبع داده |
|-------|------|-----------|
| 🪙 **سکه امامی** | سکه | TGJU (کل تاریخچه) + محاسبه‌ی مشتق |
| 🥇 **طلا ۱۸ عیار** | گرم | TGJU + محاسبه‌ی مشتق |
| 💵 **دلار** | دلار | TGJU + ویکی‌پدیا (نرخ آزاد) |
| 🏠 **مسکن تهران** | متر مربع | گزارش‌های بانک مرکزی و مرکز آمار |
| 🏦 **سپرده بانکی** | تومان | مصوبه شورای پول و اعتبار (سود سالانه) |

### مثال: سال ۱۳۷۰ — هر ۱,۰۰۰ تومان آن سال

| بازار | قیمت آن سال | هر ۱,۰۰۰ تومان آن سال امروز | ضریب |
|-------|------------|---------------------------|-------|
| 🪙 سکه امامی | ۹,۴۲۵ تومان | **۲۸,۲۱۲,۹۸۵** تومان | ۲۸,۲۱۳× |
| 🥇 طلا ۱۸ | ۱,۱۵۹ تومان | **۲۲,۵۹۰,۴۴۷** تومان | ۲۲,۵۹۰× |
| 💵 دلار | ۱۴۲ تومان | **۱,۸۵۷,۷۴۶** تومان | ۱,۸۵۸× |
| 🏠 مسکن | ۱۰۰,۰۰۰ تومان | **۱,۱۰۰,۰۰۰** تومان | ۱,۱۰۰× |
| 🏦 سپرده | نرخ ۱۲٪ | **۱۶۰,۴۷۱** تومان | ۱۶۰× |

## داده‌ها و عمق تاریخی

| دارایی | سال‌های موجود | روش |
|--------|--------------|-----|
| دلار | **۱۳۵۷ تا ۱۴۰۵** | TGJU (۱۳۹۰+) + جدول ویکی‌پدیا (۱۳۵۷–۱۳۸۹) |
| اونس جهانی | **۱۳۵۸ تا ۱۴۰۵** | TGJU `ons` |
| طلا ۱۸ | **۱۳۵۸ تا ۱۴۰۵** | TGJU (۱۳۹۲+) + مشتق از اونس×دلار |
| سکه امامی | **۱۳۵۸ تا ۱۴۰۵** | TGJU (۱۳۸۹+) + مشتق از طلا۱۸ × ۸.۱۳۳ گرم |
| مسکن تهران | **۱۳۵۰ تا ۱۴۰۴** | جدول سالانه‌ی بانک مرکزی / مرکز آمار |
| نرخ سود سپرده | **۱۳۶۳ تا ۱۴۰۵** | مصوبه شورای پول و اعتبار |

### فرمول‌های مشتق

```
gold18_toman = ounce_usd × usd_toman × (0.75 / 31.1035)     # ۱۸ عیار = ۷۵٪ خلوص
coin_toman   = gold18_toman × 8.133                          # سکه امامی = ۸.۱۳۳ گرم طلا۱۸
```

**صحت‌سنجی:** برای سال ۱۴۰۵، طلا۱۸ مشتق‌شده ۲۶,۱۵۴,۷۳۵ تومان در برابر
۲۶,۱۷۹,۴۰۰ تومان واقعی — اختلاف **۰.۱٪** ✅

## API داده (TGJU)

```bash
https://api.tgju.org/v1/market/indicator/summary-table-data/{sym}
  ?lang=fa&order_dir=desc&draw=1&start={offset}&length={page}
```

نمادهای استفاده‌شده: `price_dollar_rl` · `sekee` · `sekeb` · `geram18` ·
`mesghal` · `ons`

⚠️ **نکته‌ی مهم درباره‌ی صفحه‌بندی:** پارامتر `recordsTotal` که سرور
برمی‌گرداند **پایان واقعی تاریخچه نیست**. باید تا خالی شدن صفحه ادامه داد.
همچنین `draw` باید با شماره‌ی صفحه هم‌تراز بماند (وگرنه سرور دوباره
اولین صفحه را برمی‌گرداند).

⚠️ **واحدها:** مقادیر ابزارهای ایرانی به **ریال** هستند (تقسیم بر ۱۰ → تومان)،
ولی `ons` به **دلار** قیمت‌گذاری شده و نباید تقسیم شود.

## ساختار پروژه

```
time-machine/
├── index.html         # رابط کاربری (فارسی، RTL)
├── style.css
├── app.js             # منطق محاسبه
├── history.json       # ← تولیدشده: تاریخچه‌ی قیمت‌ها
├── static_data.json   # ← مسکن + نرخ سود + برچسب‌ها
├── dollar_history.json # ← جدول نرخ دلار ۱۳۵۷–۱۳۸۹ (ویکی‌پدیا)
└── build_history.py   # سازنده‌ی history.json
```

## اجرای محلی

```bash
python3 build_history.py         # بازسازی history.json (~۵ دقیقه)
python3 -m http.server 8000      # http://localhost:8000
```

## به‌روزرسانی دوره‌ای

`build_history.py` تاریخچه‌ی کامل را از TGJU می‌گیرد و `history.json` را
می‌نویسد. یک cron job محلی هر چند ساعت آن را اجرا و به گیت‌هاب push می‌کند
(workflow گیت‌هاب اکشنز به scope `workflow` در توکن نیاز دارد).
